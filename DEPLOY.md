# Deploy — everything in the cloud, on free tiers

**Live (2026-09-16):** app `https://interviewly-ow35.onrender.com` · Whisper
`https://chaitanya-2002--interviewly-services-voice.modal.run` · body language
`https://chaitanya-2002--interviewly-services-body.modal.run` · Redis `interviewly` on Upstash.

Four pieces, three accounts, no credit card. (Hugging Face Docker Spaces became PRO-only in
2026, so the Python services run on Modal instead; the HF files under `deploy/hf/` still work if
you have PRO.)

| Piece | Host | Free tier | URL you get |
|---|---|---|---|
| Whisper + Team 2 settings + Team 4 analysis | Modal, `deploy/modal/interviewly_services.py` | $30/month credits, no card; scales to zero | `https://<workspace>--interviewly-services-voice.modal.run` |
| Body language (Team 3) | Modal, same app | same | `https://<workspace>--interviewly-services-body.modal.run` |
| App (UI + BFF + Gemini) | Render web service, Docker (`render.yaml`) | 512 MB, sleeps after 15 min idle | `https://interviewly-<hash>.onrender.com` |
| Sessions + reports | Upstash Redis | 256 MB, 500k commands/month | REST URL + token |

## Modal (replaces the HF Space steps below)

```bash
cd deploy && python -m venv .venv && .venv/Scripts/pip install modal
.venv/Scripts/python -m modal setup                                   # browser login, once
.venv/Scripts/python -m modal secret create interviewly SERVICE_TOKEN=<random hex>
.venv/Scripts/python -m modal deploy modal/interviewly_services.py    # prints both URLs
```

Redeploy after changing `voice_to_text/`, `body_language/` or `Team3_Body_language/`: run the
last command again (images are cached; ~30 s).

Render has no disk on the free plan, so the app mirrors every session, audit event and behavioral
record to Redis and rehydrates on boot. Locally nothing changes — no Upstash env → JSON files in
`frontend/.data/` as before.

Cold starts: Render ~40 s after idle; a Space ~30 s (Whisper model load) after 48 h idle. Tell
testers the first page can take a minute.

## 0. One-time prep (your laptop)

```bash
python deploy/hf/prepare.py      # writes deploy/hf/out/voice and deploy/hf/out/body
```

Pick a shared secret for the services, e.g. `openssl rand -hex 24` (or any long random string).
Call it `SERVICE_TOKEN` below — same value in all three places.

## 1. Hugging Face — two Spaces

1. https://huggingface.co → Sign up → **New Space**.
2. Name `interviewly-voice`, SDK **Docker**, hardware **CPU basic (free)**, visibility Public
   (private Spaces work too; the app calls it with the token either way).
3. Upload the contents of `deploy/hf/out/voice/` (Files tab → *Add file* → drag the folder, or):
   ```bash
   pip install -U huggingface_hub && huggingface-cli login
   huggingface-cli upload <user>/interviewly-voice deploy/hf/out/voice . --repo-type space
   ```
4. Space → Settings → **Variables and secrets** → New secret `SERVICE_TOKEN` = your token.
5. Wait for *Running* (first build ~10 min: torch + whisper model baked in).
   Check `https://<user>-interviewly-voice.hf.space/health` → `{"ok":true,...}`.
6. Repeat for `interviewly-body` with `deploy/hf/out/body/` (build ~5 min, MediaPipe).

## 2. Upstash — Redis

1. https://upstash.com → Sign up → **Create database** (Redis, region closest to Render's,
   e.g. `us-east-1` for Render Oregon/Ohio; any is fine).
2. Copy **UPSTASH_REDIS_REST_URL** and **UPSTASH_REDIS_REST_TOKEN** from the REST API box.

## 3. Render — the app

1. https://render.com → Sign up with GitHub → **New → Blueprint** → pick this repo, branch
   `prod`. Render reads `render.yaml` and creates the `interviewly` web service.
2. It asks for the `sync: false` env vars — fill in:

   | Key | Value |
   |---|---|
   | `GEMINI_API_KEY` | your Gemini key (create a fresh one; rotate any key that was ever pasted in chat) |
   | `WHISPER_URL` | `https://<user>-interviewly-voice.hf.space` |
   | `BODY_LANGUAGE_URL` | `https://<user>-interviewly-body.hf.space` |
   | `SERVICE_TOKEN` | the shared secret |
   | `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` | from Upstash |
   | `CONSOLE_DEV_PASSWORD` | reviewer console password you will share with reviewers |

   `CONSOLE_COOKIE_SECRET` is generated by Render; `GEMINI_MODEL` defaults to `gemini-3.5-flash-lite`.
3. Deploy (first Docker build ~8 min). Open `https://interviewly.onrender.com/setup`.
4. Sign in to the console once and check `/api/v1/console/health`: `whisper_reachable` and
   `body_language_reachable` must be `true`.

Camera and microphone need HTTPS — Render and Spaces give it, so voice + camera work for testers.

## 4. Share with testers

- Candidate: `https://interviewly.onrender.com/setup` → interview → review at the end.
- Reviewer: `https://interviewly.onrender.com/console` (any work email + `CONSOLE_DEV_PASSWORD`).
- Reviews list: `/review` shows every practice interview on the server (practice mode has no
  accounts — anyone with the URL sees the list; fine for a test round, not for real candidates).

## Updating

Push to `prod`; Render redeploys automatically. Spaces: re-run `prepare.py` and upload again
only when `voice_to_text/`, `body_language/` or `Team3_Body_language/` change.

## Limits to expect

- Gemini free tier: 429s when several people interview at once — a paid Gemini project removes it.
- One Render instance, 512 MB: 3–5 simultaneous interviews. Audio is held in memory between
  upload and transcription; a redeploy mid-answer loses that one recording (candidate re-records).
- Space CPU: Whisper `base` ≈ 0.5× realtime, MediaPipe ~15 fps — one or two candidates on camera
  at a time before frames start dropping (the app degrades gracefully: fewer samples, no crash).
- Upstash free: 500k commands/month ≈ thousands of interviews; each answer is a handful of writes.
